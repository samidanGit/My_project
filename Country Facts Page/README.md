# Country Facts Page — Mini Project

This mini-project fetches live country data from the free REST Countries API and dynamically renders facts to the DOM. Built with vanilla JavaScript using modern `async/await` and `fetch`.

## Features
- **Default View:** Loads facts for Ethiopia automatically on startup.
- **Search:** Search for any country in the world.
- **State Handling:** Real-time visual indicators for **Loading**, **Success**, and **Error** states (e.g., handles 404s and offline mode).
- **Formatted Values:** Formats population values with comma separators for clean reading.

## API Used
- **REST Countries API v3.1:** `https://restcountries.com/v3.1/name/{country}`

## How to Run
1. Open the `Country Facts Page` folder.
2. Open `index.html` in any modern web browser.
