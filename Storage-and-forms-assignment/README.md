# Validated, Persistent Signup Form

A client-side signup form that validates Ethiopian phone numbers and persists submissions in localStorage.

## Features
- Full name validation (minimum 2 characters).
- Phone number regex matching Ethiopian standard (`09...` or `+2519...`).
- Theme toggle with persistence across browser refreshes.
- Error reporting via `textContent`.
- Storage exception handling using `try...catch`.

## How to Run
Open `index.html` directly in your browser.
